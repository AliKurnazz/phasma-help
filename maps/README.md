| `woodwind`       | Camp Woodwind                    |
| `pointhope`      | Point Hope                       |
| `nells`          | Nell's Diner                     |

| `restricted`     | Sunny Meadows Restricted         |
| `brownstone`     | Brownstone High School           |
| `prison`         | Prison                           |

Use images you made yourself or have permission to use. Map lists live in `js/maps.js`.
